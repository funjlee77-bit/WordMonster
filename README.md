# 단어 몬스터 탐험대 🐉📖

GRADE 5 Key Words 영단어 500개(1~25과)를 친구 몬스터와 함께 익히는 **iPad용 설치형 웹앱(PWA)**입니다.
서버·회원가입·유료 서비스 없이 작동하고, 한 번 준비하면 **인터넷 없이도** 모든 기능을 쓸 수 있어요.

- 25개 탐험 지역 = 교재 25개 Chapter. 처음부터 모든 지역(여러 개, 전체도 가능)을 고를 수 있어요.
- 모든 단어를 **뜻 → 영어 쓰기**, **영어 → 뜻 쓰기** 두 방향으로 직접 입력해서 연습해요(객관식 없음).
- 채점은 교재 표기 기준이에요. 영어 정답은 엑셀 E열(엄격), 뜻 정답은 D열 전체이고 뜻은 부호·띄어쓰기만 무시해요.
- 과일 몬스터 50종(일반 30 · 희귀 15 · 전설 5)을 탐험하며 포획해요. 희귀·전설은 꾸준히 복습해야 나타나요.
- 틀린 단어는 같은 판 2~4문제 뒤에 다시 나오고, 다음 판에서도 먼저 나와요. 1·3·7일 간격 복습을 도움 없이 통과해야 ‘숙련’이 돼요.
- 학교 실전 모드(시험지처럼 풀고 마지막에 채점), 부모 메뉴(성취도·정답 수정·채점 설정·백업)가 있어요.

## 0. 저장소 이름에 따라 바꿀 값 (한 곳)

`app.config.json` 파일 하나만 보면 돼요.

```json
{ "repoName": "word-monster" }
```

- GitHub 저장소 이름을 `word-monster`로 만들면 **아무것도 바꿀 필요가 없어요.**
- 다른 이름(예: `doyun-words`)으로 만들었다면 `"repoName": "doyun-words"`로 바꿔 주세요.
  (이 값은 내 컴퓨터에서 확인할 때 쓰여요. GitHub에서 빌드할 때는 저장소 이름이 자동으로 들어가요.)
- 주소가 `https://아이디.github.io/` 처럼 저장소 이름 없이 끝나는 특수 저장소(`아이디.github.io`)는 이 앱 구조와 맞지 않으니 일반 저장소 이름을 써 주세요.

## 1. 내 컴퓨터에서 확인하기

필요한 것: [Node.js](https://nodejs.org) 20 이상 (LTS 버전 설치)

```bash
npm install        # 처음 한 번
npm test           # 자동 검사 (데이터·채점·반복학습·저장)
npm run build      # 앱 만들기 → dist 폴더
npm run preview    # http://localhost:4173/word-monster/ 에서 확인
```

`npm run dev`로 띄운 개발 화면에서는 오프라인 기능이 꺼져 있어요. 오프라인까지 확인하려면 `build`를 한 뒤 `preview`로 열어 보세요.

### 단어 데이터를 다시 만들 때 (엑셀 → JSON)

1. 엑셀 파일을 `data-source/` 폴더에 넣어요. 시트 이름은 `단어목록`, 열은 A 과 / B 번호 / C 영어(교재 표기) / D 뜻 / E 철자 정답 / F 대조 확인 / G 메모예요. `.xlsx` 파일은 하나만 둬 주세요.
2. `npm run convert` 를 실행해요.
3. 결과는 `src/data/words.json`, 검사 결과는 `data-source/검사결과.txt`에 저장돼요.
   검사(총 500개, Chapter별 20개, 번호 누락·중복, C·D·E열 빈칸)에서 하나라도 실패하면 JSON을 만들지 않고 이유를 보여줘요.

변환 원칙: D·E열은 그대로 보존해요(NFC 정규화·앞뒤 공백 제거만 한 채점용 값을 따로 저장). 괄호를 지워서 정답을 추측하거나 과거형을 정답에 추가하지 않고, 같은 영어가 여러 Chapter에 있어도 합치지 않아요.

## 2. GitHub에 올리기

1. [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: `word-monster` (다른 이름이면 0번 참고) → **Public** → Create
3. 이 프로젝트 폴더의 파일을 모두 올려요. `node_modules`와 `dist` 폴더는 올리지 않아요.
   - 방법 A (Git 사용):
     ```bash
     git init && git add . && git commit -m "첫 버전"
     git branch -M main
     git remote add origin https://github.com/아이디/word-monster.git
     git push -u origin main
     ```
   - 방법 B (웹): 저장소 화면의 **uploading an existing file**에서 폴더 내용을 끌어다 놓기.
     `.github` 폴더가 빠지지 않게 주의하세요. 숨김 폴더라 끌어다 놓기에서 빠질 수 있어요. 빠졌다면 **Add file → Create new file**에서 이름을 `.github/workflows/deploy.yml`로 하고 내용을 붙여 넣어요.

## 3. GitHub Pages 켜기

1. 저장소 → **Settings** → 왼쪽 **Pages**
2. **Build and deployment → Source**를 **GitHub Actions**로 선택해요.
3. **Actions** 탭에서 “GitHub Pages 배포”가 초록색 ✔이 될 때까지 기다려요(1~3분). 실패(빨간 ✕)하면 눌러서 어느 단계인지 확인해요. 자동 검사(npm test)가 실패해도 배포되지 않아요.
4. 주소: `https://아이디.github.io/word-monster/`

이후에는 `main`에 변경을 올릴 때마다 자동으로 다시 배포돼요.

> **공개 안내**: Public 저장소와 Pages 주소는 누구나 볼 수 있어요. 앱에 들어 있는 교재 단어 목록(JSON)도 방문자가 내려받을 수 있어요. 학습 기록은 각 기기에만 저장되고 GitHub에는 올라가지 않아요. 아이의 실명은 앱 어디에도 넣지 마세요(탐험가 별명만 사용).

## 4. iPad에 설치하기 (홈 화면에 추가)

1. iPad **Safari**로 `https://아이디.github.io/word-monster/` 접속
2. 공유 버튼(□↑) → **홈 화면에 추가** → 추가
3. 홈 화면의 **단어몬스터** 아이콘으로 앱을 열어요 (**인터넷 연결된 상태로**)
4. 첫 화면에서 친구 몬스터를 고르고, 위쪽 표시가 **✅ 오프라인 사용 준비 완료**가 될 때까지 기다려요
   - ⏳ 준비 중: 파일을 받는 중이에요
   - ⚠️ 준비 실패: 인터넷을 확인하고 표시를 눌러 **다시 시도**
5. 이제부터는 **홈 화면 아이콘으로만** 공부해요.
   Safari 탭에서 연 앱과 홈 화면 앱은 기록이 따로 저장될 수 있어요. 기기끼리도 기록이 공유되지 않아요.

## 5. 오프라인 확인 (부모님이 한 번 해 보세요)

1. Safari에서 접속
2. 홈 화면에 추가
3. 홈 화면 앱을 **온라인에서** 열기
4. **✅ 오프라인 사용 준비 완료** 확인
5. 설정에서 **Wi-Fi와 셀룰러 끄기** (또는 에어플레인 모드)
6. 앱 전환 화면에서 앱을 **위로 밀어 완전히 닫고**, 홈 화면에서 다시 실행
7. **한 번도 열어 보지 않은 Chapter**(예: 25)를 골라 탐험 한 판 진행
8. 앱을 다시 완전히 닫았다가 실행해서, 지도에 그 Chapter의 ‘만난 단어’ 기록이 남아 있는지 확인

## 6. 업데이트

- 새 버전을 배포하면, 앱을 인터넷에 연결해서 열었을 때 **“새 버전이 준비됐어요”** 알림이 떠요. 탐험이나 시험 중에는 알림이 뜨지 않아요.
- **지금 적용**을 눌러야 바뀌어요. 그전까지는 이전 버전이 그대로 작동하고, 새 파일을 받다 실패해도 이전 버전으로 계속 공부할 수 있어요.
- 학습 기록(IndexedDB)은 앱 파일 캐시와 따로 저장돼서 업데이트해도 유지돼요.

## 7. 백업과 복원

- **부모 메뉴**(어른 확인 곱셈 문제) → **💾 백업·복원** → **백업 파일 만들기**
  iPad에서는 공유 창이 뜨면 **“파일에 저장”**을 골라요. 파일에는 학습 기록, 게임 상태, 설정, 정답 수정, 시험 기록, 데이터·교재 버전이 들어가요.
- 복원: **백업 파일 고르기** → 내용 요약(기록 수·만든 날짜 등) 확인 → **복원하기**. 잘못된 파일은 복원하지 않아요.
- ⚠️ Safari의 웹사이트 데이터 삭제나 기기 저장 공간 정리로 오프라인 파일과 기록이 지워질 수 있어요. 영구 보존은 보장되지 않으니 **가끔 백업**해 주세요. 지워졌다면 인터넷에 연결해서 다시 열고, 백업 파일로 복원하면 돼요.

## 학습 규칙 (부모님용)

**채점**: 앞뒤 공백 제거와 NFC 정규화를 하고 동의어는 인정하지 않아요.
- **영어 쓰기(뜻 → 영어)**: 기본은 엄격 채점이에요. 대소문자·띄어쓰기·문장부호·괄호를 모두 구분해요.
- **뜻 쓰기(영어 → 뜻)**: **부호(괄호·~·쉼표·따옴표·/·- 등)와 띄어쓰기만 무시**해요. 글자와 순서는 D열과 같아야 해요. 예: `(~한 상태로) 변하다, 되다`가 답이면 `한상태로변하다/되다`, `한 상태로 변하다 되다` 모두 정답이에요. `변하다, 되다`(일부만 씀)나 travel의 `여행하다, 이동하다`(순서 바뀜)는 오답이에요. 이렇게 맞힌 답도 정식 정답이라 숙련도에 들어가요.
- secrete의 정답은 `비밀로 하다`이고 `숨기다`는 인정하지 않아요. take(took) a walk의 영어 정답은 `take a walk`예요.
- 부모 메뉴에서 영어 쓰기의 대소문자·띄어쓰기·문장부호 검사를 각각 끌 수 있어요. 이렇게 맞힌 답은 ‘완화 정답’으로 따로 기록되고 숙련도를 올리지 않아요.
- 부모 메뉴 → 단어·정답에서 항목별 대표 정답 변경·대체 정답 추가가 가능해요. 교재 원문은 바뀌지 않고, 수정 사항은 따로 저장돼요. 저장할 때 그 항목의 숙련도를 유지할지 초기화할지 고를 수 있어요.
- 같은 뜻인 다른 단어(reporter/journalist=기자, university/college=대학, huge/giant=거대한, awful/terrible=끔찍한, risk/danger=위험)는 문제에 Chapter·번호를 표시해요. 다른 쪽 단어를 쓰면 “같은 뜻의 다른 단어예요”라고 알려 주지만 정답으로 인정하지는 않아요.

**숙련 단계**(영어 쓰기·뜻 쓰기 각각): 처음 만남 → 연습 중 → 1일 뒤 복습 → 3일 뒤 복습 → 7일 뒤 복습 → 숙련
- 단계는 **도움 없이 + 엄격 채점 정답**일 때만 올라요. 힌트, 정답 보기, 따라 쓰기, 완화 정답은 제외예요.
- 복습 단계는 예정일 당일이나 그 이후에 맞혀야 다음 단계로 가요. 같은 날짜에는 한 번만 오르고, 그날 틀린 적이 있으면 그날은 오르지 않아요.
- 틀리면 ‘연습 중’으로 내려가고 다음 날부터 다시 복습해요. 이전 기록과 게임 보상은 지워지지 않아요.
- 두 방향 모두 7일 뒤 복습까지 통과하면 **숙련(양방향)**이에요. 숙련 뒤에도 30일 간격으로 다시 나와요.
- **날짜 계산**: iPad의 현지 날짜(자정 기준)로 하루를 나눠요. “1일 뒤”는 다음 날 0시부터 복습 대상이에요(코드: `src/core/dates.ts`, `src/core/srs.ts`).

**출제 순서**: ① 같은 판에서 다시 물을 차례가 된 오답 ② 이전 판에서 남은 오답 ③ 복습 예정일이 지난 단어 ④ 아직 안 본 단어 ⑤ 일반 복습
- 일반 탐험은 새 단어 자리(문제 수의 약 25%)를 남겨 둬요. 최근 5판에 자주 나온 단어는 뒤로 미뤄요(`src/core/scheduler.ts`).
- 오답은 다른 문제 2~4개 뒤에 같은 방향으로 한 번 더 나와요. 한 판의 문제 수는 그대로이고, 자리가 없으면 다음 판으로 넘어가요.
- 👾 오답 몬스터 추격: 선택한 범위의 오답만 연습해요. 범위 밖 오답은 지도 화면의 ‘전체 Chapter 오답 복습’으로 따로 골라요.

**게임**: 한 판 기본 8문제(5·8·10 선택), 시간제한 없음. 끝까지 하면 별(1~3)·경험치·코인을 받고, 틀려도 캐릭터나 보상을 잃지 않아요. 장식은 모습만 바꾸고 채점에는 영향이 없어요.

**과일 몬스터 포획** (`src/core/capture.ts`, 몬스터 목록 `src/core/fruits.ts`)
| 등급 | 수 | 나타나는 조건 | 포획 조건 |
|---|---|---|---|
| 일반 | 30 | 그 Chapter 탐험에서 바로 | 별 2개 이상 |
| 희귀 (RARE) | 15 | 그 Chapter에서 ‘1일 뒤 복습’을 통과한 단어 5개 이상 | 별 3개 |
| 전설 (LEGEND) | 5 | Chapter 1~5, 6~10, 11~15, 16~20, 21~25 묶음별로 양방향 숙련 단어 20개 이상 | 힌트·정답 보기 없이 별 3개 |
- 희귀·전설은 몬스터 뒤에 빛나는 배경과 RARE / LEGEND 글자가 나오고, 나타날 때 출현 화면, 잡으면 포획 이벤트 화면이 나와요.
- 포획에 실패해도 사라지지 않고 다음에 또 나타나요. 처음 포획하면 보너스 코인(일반 5 · 희귀 20 · 전설 50)을 받아요.
- 도감에서 못 잡은 몬스터를 누르면 나타나는 조건과 지금 진행 정도(예: 3/5)를 볼 수 있어요.

## 폴더 구조

```
app.config.json            저장소 이름 (한 곳)
data-source/               원본 엑셀 + 검사결과.txt
scripts/convert-xlsx.mjs   엑셀 → JSON 변환·검사
scripts/build-sw.mjs       오프라인용 sw.js 생성(전체 파일 사전 캐시)
scripts/serve.mjs          GitHub Pages와 같은 하위 경로로 미리보기
src/data/words.json        변환된 500단어 (앱에 포함)
src/core/                  채점·반복학습·출제·저장·백업 로직
src/art/Characters.tsx     직접 그린 친구 몬스터·장식·배경 SVG
src/art/FruitMonster.tsx   과일 몬스터 50종 그림 생성기
scripts/gallery.mjs        과일 몬스터 50종 한눈에 보기 이미지 만들기
src/screens/               화면들
tests/unit/                자동 검사 (npm test)
tests/e2e/                 브라우저 오프라인 검사 (Python Playwright + Chrome 필요, 선택)
.github/workflows/deploy.yml  자동 빌드·배포
```
